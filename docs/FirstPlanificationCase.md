- admin
- user
- support agent

- ver su historia de cambios de cada ticket creado
- comentar cualquier ticket en una seccion especial que sera como chat global
- calificar la atencion de soporte solo cuando su ticket este en estado cerrado

- asignar a cada ticket un agent diferente
- cambiar la prioridad de un ticket 
- como bloquear a un user por mal comportamiento
- poner un ticket en la seccion de FAQ el cual estara con visibilidad global y anonimo
